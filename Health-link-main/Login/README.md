# HealthLink Full-Stack Application

### How to run the backend:
1. Open a terminal in the `healthlink-backend` folder.
2. Install the required dependencies: `pip install -r requirements.txt`
3. Run the server: `python app.py`
*(The SQLite database will automatically generate upon running).*

### How to run the frontend:
1. Open the main project folder in VS Code.
2. Use the "Live Server" extension to open `Login.html`.
